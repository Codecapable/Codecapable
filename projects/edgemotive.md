# EdgeMotive

[Visit the live product](https://backtest.software/)

EdgeMotive is a hosted service for historical strategy testing. It gives users a way to run repeatable tests and review private reports with stated assumptions, charts, and trade histories.

## What I built

- The Python service connecting a test request to a report
- Data checks and repeatable report generation
- Account access, saved work, private report delivery, and payment flows
- Deployment and operational maintenance

The project demonstrates end-to-end service development, careful handling of test inputs, and clear presentation of complex results. The implementation and strategy details remain private.
